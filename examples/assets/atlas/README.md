# Atlas artwork

Generated with the built-in imagegen tool for this project. Exact prompts are in [prompts.json](prompts.json).

- `knight.png`: transparent equipment figure; profile/shop crops use AtlasTexture regions.
- `city_map.png`: original illustrated city texture; markers and navigation controls are separate nodes.
- `cathedral.png`: original quest banner illustration.
- `items.png`: transparent 4 × 3 sprite sheet, 362 pixels per cell. Item frames, quantities, tooltips and bindings are separate nodes.

These images are illustrative replacements, not extracted artwork from the user's atlas. The supplied atlas is retained under `examples/references` only as an authoring reference. No external image API or CLI fallback was used.
